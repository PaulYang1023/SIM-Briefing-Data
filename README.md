# ✈️ Tigerair Taiwan Simulator Briefing Data Repository (SIM-Briefing-Data)

This repository serves as the official data repository for **Tigerair Taiwan Simulator Briefings & Profiles Generator**.

## 📁 Structure

```text
courses/
├── 2026-PT-06.json
├── A-FFS-1.json
└── ...
```

Each course is stored as an independent JSON file under the `courses/` directory.

## 🔐 Access & Audit
- **Generator App**: [https://sim-briefing-generator.vercel.app/generator/builder.html](https://sim-briefing-generator.vercel.app/generator/builder.html)
- Every publication or revision rollback is automatically committed to this repository with exact author tags (e.g. `Captain Paul Yang`) and timestamps.
